# ASC Standards

Inscribed ethics standards for software: plain-language rules that code can be certified against by an AI jury, with the result inscribed on Solana.

**These are the first versions of the standards and the certification rules. All are Drafts.** They're published for review and will change before they're inscribed as Final.

| Standard | Title | Version | Rules | Status |
|---|---|---|---|---|
| [ASC-0](standards/ASC-0.md) | Standards process and numbering | 1.0 | | Draft |
| [EDO](standards/EDO.md) | Ethical Device Operations | 1.0 | 5 | Draft |
| [EAO](standards/EAO.md) | Ethical Agent Operations | 1.0 | 10 | Draft |
| [ETC](standards/ETC.md) | Ethical Treasury Conduct | 1.0 | 12 | Draft |
| [EVC](standards/EVC.md) | Ethical Vesting Contracts | 1.0 | 8 | Draft |
| [EMO](standards/EMO.md) | Ethical Model Operations | 1.0 | 10 | Draft |

- [CERTIFICATION.md](CERTIFICATION.md): how a repository push is certified, checksummed, scored and inscribed.
- [badges/](badges/): the ASCII badge for each standard, inscribed with every passing certificate.
- [schema/certificate.schema.json](schema/certificate.schema.json): the inscribed certificate format.
- [examples/](examples/): an example certificate and its badge (example data, not a real review).

Standards are maintained by Rex St. John at Verafy. Proposals and changes go through pull requests per [ASC-0](standards/ASC-0.md).

A certificate is a code review of one commit against a published standard. It isn't a legal, regulatory or safety certification.
